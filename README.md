# Lumen

Свой браузер на ядре Chromium: интерфейс в стиле Safari, функции в духе Opera GX.

| Платформа | Движок | Папка |
|---|---|---|
| Windows / macOS / Linux | Chromium (через Electron) | `desktop/` |
| Android | Chromium (системный Android WebView) | `android/` |

Общие файлы (список блокировки, стартовая страница) лежат в `shared/` и используются обеими платформами.

## Установка

### Windows (готовый установщик)

Вкладка **Releases** → `Lumen-Setup-x.y.z.exe` → запустить. Установщик мастером: выбор папки, ярлыки на рабочем столе и в «Пуске», удаление через «Параметры → Приложения». Дополнительных программ (Node.js, Visual C++ и т.п.) ставить не нужно: Chromium и всё необходимое упакованы внутрь установщика.

> Установщик не подписан цифровым сертификатом, поэтому Windows SmartScreen покажет предупреждение: «Подробнее» → «Выполнить в любом случае». Убрать его можно только покупкой сертификата подписи кода.

### Android (APK)

1. Вкладка **Releases** → `Lumen-android.apk`, скачать на телефон.
2. Открыть файл → Android попросит разрешить «установку из неизвестных источников» для браузера/файлового менеджера — разрешить и установить.
3. Нужен Android 10 или новее.

Это debug-сборка, подписанная автоматическим debug-ключом: для своего телефона она подходит, для Google Play нужна релизная сборка со своим keystore (`gradle bundleRelease`).

## Как собрать установщик самому

**Вариант 1 — в один клик, Windows:** запустить `build-windows.bat` в корне репозитория. Скрипт сам поставит Node.js (через winget), установит зависимости, соберёт и откроет папку `desktop/dist` с `Lumen-Setup-x.y.z.exe`. Если видите ошибку про symbolic link — включите «Режим разработчика» в параметрах Windows или запустите файл от имени администратора.

**Вариант 2 — в консоли:**

```bash
cd desktop
npm install
npm start          # запуск без установки
npm run dist       # установщик в desktop/dist
npm run smoke      # автотест: запускает приложение и проверяет вкладки, панели, усыпление
```

**Вариант 3 — выпуск релиза через GitHub:** Actions → `release` → Run workflow (указать тег, например `v0.1.0`) или `git tag v0.1.0 && git push --tags`. В релизе появятся `.exe` и `.apk`.

## Android: сборка вручную

Открыть папку `android/` в Android Studio → Run (на эмуляторе или подключённом телефоне с включённой отладкой по USB). Из консоли: `cd android && gradle assembleDebug`, файл появится в `android/app/build/outputs/apk/debug/`.

## Что уже есть

**Интерфейс (Safari-стиль)**
- компактная панель: навигация, адресная строка-«таблетка» по центру (показывает только домен, полный адрес при фокусе), вкладки равной ширины под ней
- темы: как в системе, светлая, тёмная и фирменные (GX, Аврора, Уголь, Океан, Бумага), свой акцентный цвет
- обои новой вкладки: галерея или своё изображение
- что открывать при запуске: страница Lumen, пустая вкладка, сайт или набор закладок
- масштаб интерфейса, размер шрифта и масштаб страниц
- Android: адресная строка и кнопки внизу, как в Safari на iPhone

**Функции (GX-стиль)**
- боковая панель: можно выключить целиком и выбрать, какие разделы показывать
- блокировщик рекламы и трекеров (`shared/blocklist.txt`, счётчик блокировок)
- усыпление неактивных вкладок: освобождает память, вкладка перезагружается при возврате
- менеджер вкладок по памяти (аналог Hot Tabs Killer): МБ на вкладку, «Сон» и закрытие
- принудительный тёмный режим для сайтов
- менеджер паролей: предложение сохранить пароль со страницы, ручное добавление, подстановка в форму. На десктопе секрет шифруется средствами ОС, на Android — ключом Android Keystore
- загрузки: файлы складываются в системную папку «Загрузки», список с паузой и открытием
- поиск по странице (Ctrl+F), запрос разрешений сайта (камера, геолокация, уведомления)
- закладки, история, очистка данных сайтов, горячие клавиши (Ctrl+T/W/L/F/J, Ctrl+Shift+S/P, Ctrl+Tab, F12, масштаб)
- один экземпляр приложения: повторный запуск с ссылкой открывает новую вкладку

## CI

- `build.yml`: на каждый push проверяет синтаксис, **запускает реальное приложение** (smoke-тест на Linux и Windows), собирает десктоп под три ОС и debug-APK.
- `release.yml`: собирает установщик Windows и APK и публикует их в Releases.

## Ограничения

- Это не форк Chromium, а оболочка над ним: Electron на десктопе и системный WebView на Android. Версия Chromium на десктопе = версия Electron (в `package.json` стоит `latest`, чтобы при пересборке получать свежие патчи безопасности); на Android — то, что обновляет Google через Play (Android System WebView).
- Установщик не обновляется сам: новая версия = новый релиз и установка поверх старой.
- Нет расширений Chrome, синхронизации между устройствами и Safe Browsing. Пароли остаются только на этом устройстве.
- Разрешения сайтов на десктопе спрашиваются перед доступом к камере, геолокации и уведомлениям и запоминаются для сайта.
- Вход через Google во встроенных браузерах может блокироваться самим Google.
- Из Opera GX пока нет: VPN, лимитеров CPU и сети, встроенных плееров и мессенджеров, GX Corner.
- Lumen не зарегистрирован как браузер по умолчанию в Windows (это отдельная регистрация в реестре).

## Структура

```
desktop/   Electron: main.js (вкладки, сессия, IPC), preload.js, themes.js, vault.js, renderer/ (интерфейс), smoke.js
android/   Kotlin: MainActivity.kt, Store.kt (настройки и обои), Vault.kt (пароли), Panels.kt, Adblock.kt
shared/    blocklist.txt, start.html
```
